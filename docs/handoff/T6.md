# T6 preset-browser view model

Survey classification: `createAxisPresetBrowserPartView` is the sole runtime export and is rune-stateful, host-singleton-dependent, and DOM/lifecycle-dependent; `AxisPresetBrowserPartView` is type-only. No pure exports exist for a node test.

Meaningful isolated unit coverage could not be added without a production change. The factory directly imports `library`, `editor`, `history`, conversion, controller, runtime, recency, and device-name singletons and executes `$effect`, `onMount`, DOM globals, timers, and storage. A minimal host cannot be supplied, and component mounting is prohibited. Existing sibling pure modules cover selection gestures, sorting/query/data, offline empty-slot gating, row caps, load dispatch, filters, and menus; testing the 870-line orchestration itself requires a future host-injection extraction.
