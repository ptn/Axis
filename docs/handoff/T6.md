# T6 preset-browser view model

`AxisPresetBrowserViewModel` is the host-injected domain orchestration layer. It composes selection and range marking, query/filter state, sorting, online-only empty device slots, row caps, rename/load routing, and saved-filter persistence without Svelte, DOM, timers, browser storage, or app singletons.

`createAxisPresetBrowserPartView` preserves the panel-facing API and remains the thin rune adapter. It supplies live production getters through `createAxisPresetBrowserViewModelHost` and retains reactive projection, lifecycle binding, focus/caret handling, geometry, delayed hydration, idle warming, and browser events. Node tests cover the five behavior areas without mounting components; Playwright retains DOM interaction coverage.
