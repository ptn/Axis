# T2 modulation coverage

Added 7 cases to `src/lib/graphs/modulationGraphs.test.ts` covering square/pulse and saw/ramp aliases, deterministic seeded random/noise plateaus, all-type finite/bounded/wrapping invariants, continuous cycle joins, and tempo fallbacks/modifier composition. Duty identity now includes saw directions and astable.

Saw and astable ignore Duty Cycle in the current implementation, so no forced duty-effect assertion was added. This is recorded as an unsupported behavior, not treated as a product bug.
